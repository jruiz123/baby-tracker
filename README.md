# baby-tracker
Easily manage baby diaper schedule, temp, feelings, behaviour or more in one app.

Techstack: php, js, mysql, pwa

Features:
- You as a parent can create a account to log all the activities of your baby in simple ways
- Parents can add multiple baby 
- Each has categories depending on the activity you are logging
- Parents can add alarm if you plan to monitor the next iteration of that activity
